## About

A simple blog for my ideas, ramblings, and projects related to RPGs, my own setting and my own RPG game dev adventures.

I have years of notes and half finished ideas, that will in time populate this space.

#### Technical Details

This blog is built with [Astro](https://astro.build/blog/), that ~~might~~ almost certainly will change in the future as I explore other technologies. I'm using the [Astro Bear Blog](https://github.com/harleyjwilson/astro-bearblog/tree/main) theme, inspired by the excellent [Bear Blog](https://bearblog.dev/) which hosts a number of fun RPG & OSR related blogs. 

The whole thing is deployed using [GitHub Pages](https://docs.github.com/en/pages)
